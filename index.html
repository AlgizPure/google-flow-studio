Быстрый чек-лист перед запуском генерации

1. Подготовка ассета

• Кадр дополнен до 9:16 (1080×1920) или 16:9 (1920×1080).
• Пустая зона под текст уже заложена в исходное изображение.
• Лицо и поза утверждены по брендбуку.

2. Режим генератора

• Выбран режим Frames to Video.
• В промпте удалены повторные описания внешности.
• Описано только движение, камера и поведение света.

Аудит всех элементов меню и вкладок Google Flow

Полный разбор структуры интерфейса: назначение каждой вкладки, переключателей и скрытых настроек для обеспечения 100% повторяемости результатов.

1. Вкладка «Images» (Генерация и подготовка референсов)

Keyframes

Служит для создания базовых опорных изображений, раскадровок и генерации персонажей через Nano Banana Pro.

  • Model Selector: Nano Banana Pro (максимальная точность, фотореализм кожи) vs Nano Banana (быстрые скетчи).
  • Aspect Ratio: Выбор соотношения сторон (1:1, 9:16, 16:9, 4:5, 3:4). Для видео носителей Flow принимает на входе 9:16 или 16:9.
  • Reference Slots (Слоты референсов): Позволяет привязать Subject Ref (лицо модели), Style Ref (палитра «При свете») и Composition Ref.
  • Lasso & Inpainting (Инструмент лассо): Выделение маской зоны (например, пустой стены слева) для локальной генерации плавного градиента без перегенерации лица.
  • Variations: Ползунок количества генераций (1–4).

2. Вкладка «Video» (Основной видеогенератор)

Motion Core
  • Режимы ввода:
    • Text-to-Video: Генерация из текста с нуля (не рекомендуется для Skinerica, теряется контроль стиля).
    • Frames to Video: Основной рабочий режим! Слот First Frame (старт) и опциональный Last Frame (финиш).
    • Ingredients to Video: Доступен в Veo Fast и Omni. До 3 тегированных файлов.
  • Motion Intensity (Сила движения): Числовой ползунок (1–10). Для Skinerica всегда ставить 2–4 (Low) — микродвижения, дыхание, мягкий поворот подбородка. Значения >6 приводят к искажению анатомии.
  • Camera Controls (Управление камерой): Фиксированный переключатель: Static (Locked-off), Slow Push-in, Pan Left/Right, Orbit. Для наших креативов — только Static или Slow Push-in.
  • Resolution: 360p (черновики), 720p (Omni), 1080p / 4K (Veo Quality).
  • Duration: 4s, 6s, 8s (базовый лимит 8 секунд).
  • Seed Lock (Фиксация зерна): Чекбокс сохранения сида для тестирования изменений в промпте без изменения динамики шума.
  • Native Audio: Чекбокс генерации звука. Если включен, модель синтезирует шумы комнаты и голос из кавычек.

3. Вкладка «Characters» (Реестр персонажей и консистентность)

Identity Anchor

Позволяет закрепить постоянных героинь и реальных врачей клиники, чтобы не описывать их заново.

  • New Character: Создание профиля персонажа (например, @Heroine_A, @Erica_Drawn, @Dr_Baranchikova).
  • Multi-Angle Upload: Загрузка 3 ракурсов (анфас, три четверти, профиль). Фиксирует геометрию лица и фактуру кожи.
  • Style Lock: Выбор типажа: Photorealistic Human (для героинь и врачей) vs Line Drawing (для Эрики K).
  • Voice Profile: Привязка аудиофайла голоса персонажа.
  • Синтаксис @Name: В поле промпта достаточно напечатать @Erica_Drawn, и модель автоматически связывает латентные веса с карточкой персонажа.

4. Вкладка «Scenes» (SceneBuilder & Монтажная лента)

Sequencing
  • Timeline: Горизонтальная дорожка для сборки длинных видео из отдельных шотов.
  • Extend Clip (+7s): Ключевая функция преодоления 8-секундного барьера. Фиксирует последний кадр шот-сегмента и запускает генерацию продолжения.
  • Transition Controls: Выбор типа склейки: жесткий стык (Cut), мягкое перетекание (Dissolve) или интеллектуальный морфинг.

5. Вкладка «Uploads» (Медиа-библиотека проекта)

Asset Bank

Хранилище загруженных файлов: Images (кабинеты, аппараты, портреты), Audio (сэмплы голоса, фон клиники), Video (референсы динамики). Все ассеты поддерживают тегирование (например, #krasnodar, #doctor, #device).

6. Вкладка «Tools» (Кастомные инструменты и Code Tab)

Custom Code

Среда создания собственных интерактивных микро-приложений внутри Flow. Позволяет упаковать правила стиля «Живая кожа» в удобный интерфейс с готовыми полями ввода и автоматической сборкой безошибочного промпта. Подробный разбор — в следующем разделе.

Создание кастомных инструментов во вкладке Tools

Как настроить собственный генератор под брендбук Skinerica через естественный язык и тонкий кодинг в декларативной вкладке Code.

⚙️
Зачем нужен кастомный Tool: Чтобы оператор не вспоминал каждый раз структуру промпта, негативные стоп-слова и пропорции. Кастомный инструмент дает UI с выпадающими списками услуг, привязанными персонажами и автоматической сборкой финального промпта для Veo 3.1.

Два способа создания инструмента

Способ 1: Natural Language Prompt

1. Во вкладке Tools нажать Create Tool.
2. Ввести промпт сборщика: «Create a video generator tool for Skinerica clinic. Include a scene dropdown (SMAS, Body, Laser), a character selector (@Heroine_A, @Erica), an image upload for Start Frame, and a model selector (Veo Quality vs Omni). Output prompt with locked negative space.»
3. Flow создаст рабочий интерфейс и сгенерирует код.

Способ 2: Тонкий кодинг (Вкладка Code)

1. В созданном инструменте переключиться на вкладку Code.
2. Откроется JSON/React декларативный манифест инструмента.
3. Вставить готовый код (представлен ниже), скорректировать логику интерполяции строк и валидацию полей.
4. Нажать Save & Deploy.

Промпты & Аудит ошибок flow-prompts-v1.html

Почему предыдущие промпты не работали в Google Flow, какие скрытые законы видеомоделей были нарушены, и готовые исправленные формулы.

⚠️
6 фундаментальных причин сбоя в flow-prompts-v1.html:
  1. Словесная индексация вместо UI-тегов: Конструкция «the first image for the woman, second for room» не понимается моделью. Flow требует тегирования @Character через меню или единый Start Frame.
  2. Конфликт режимов: Попытка скормить 3 ингредиента модели Veo 3.1 Quality. Quality поддерживает только Frames to Video. Ингредиенты есть только у Veo Fast и Omni!
  3. Ловушка повторного описания (Start Frame Trap): Если дан стартовый кадр, нельзя заново описывать цвет платья, возраст и черты лица в промпте! Модель пытается перегенерировать пиксели, и лицо «плывет». Описывать нужно ТОЛЬКО кинематику (куда повернулась, как вздохнула).
  4. Перегруз микро-таймкодами: Текстовые интервалы [00:00-00:02], [00:02-00:05] на 8 секундах вызывают рывки и галлюцинации. Допустимо максимум 1–2 плавных действия на шот.
  5. Парадокс негативных формулировок: Фраза «Hands stay down, away from the face» провоцирует диффузию нарисовать руки у лица. Запреты пишутся в позитивной форме: «Arms rest calmly at her sides».
  6. Дрифт зоны текста: Попытка описать словами «caption zone melts into room» не работает. Пустое поле должно быть жестко заложено в исходный файл стартового кадра.

Голос бренда & Клонирование для Эрики

      
Создание, загрузка, настройка и сохранение эталонного голоса Эрики для стабильного воспроизведения от модели к модели.


      

        

          
Акустический паспорт голоса Эрики

          Voice Blueprint
        

        
    
          
  • Тембр: Теплый женский голос, возраст 30–35 лет, мягкая грудная подача.
    • 
          
  • Тон: Документальный, эмпатичный коллега. Без слащавости, без интонаций автоответчика или агрессивного сейлза.
    • 
          
  • Темп: Спокойный, неторопливый (~110–120 слов в минуту). Разборчивые паузы между смысловыми блоками.
    • 
          
  • Акустическая среда: Сухая комната без реверберации и эха, деликатный шелест бумаги.
    • 
        

      


      
Пошаговый процесс настройки собственного голоса во Flow

      

        

          Шаг 1: Подготовка эталонного аудио-якоря (Audio Anchor)
          
Записать 20–30 секунд чистой речи диктора в формате WAV (48 кГц, 24 бит, моно). Без музыки и компрессии. Текст записи — слоган бренда («Мы смотрим на кожу при свете...»).

        

        

          Шаг 2: Загрузка в Uploads
          
В панели Uploads выбрать вкладку Audio и загрузить erica_master_voice_v1.wav. Присвоить тег #voice_anchor.

        

        

          Шаг 3: Привязка к персонажу в Characters
          
Открыть карточку персонажа @Erica_Drawn или @Erica_Droid. В секции Voice Profile привязать загруженный аудиофайл. Сохранить персонажа.

        

        

          Шаг 4: Использование в генераторе
          
В Gemini Omni Flash 1.1 модель автоматически подхватывает аудио-референс персонажа для липсинка. В Veo 3.1 пишется реплика в кавычках, и тег @Erica направляет интонационный контур.

Склейка длинных видео (>8 секунд) & Вкладка Scenes

      
Методика непрерывного продления шотов с сохранением лица, света и окружения без артефактов морфинга.


      

        
⏱️

        

          Ограничение моделей: Базовый шот Veo 3.1 генерирует максимум 8 секунд. Создание роликов на 15, 30 или 60 секунд строится на цепочке склеек, где каждый следующий сегмент берет за основу последний кадр предыдущего.
        

      


      
Метод 1: Нативный SceneBuilder Extend (+7 секунд)

      

        
    
          
  1. Сгенерировать первый базовый клип (0–8 с) во вкладке Video.
    2. 
          
  2. Навести на готовый клип и нажать Add to Scene (клип падает на таймлайн вкладки Scenes).
    3. 
          
  3. На конце клипа нажать иконку Extend (+).
    4. 
          
  4. Система автоматически фиксирует Last Frame предыдущего клипа как First Frame для следующего сегмента длиной 7 секунд.
    5. 
          
  5. ПРАВИЛО ПРОМПТА ПРОДЛЕНИЯ: Не переписывать сцену! Описывать исключительно продолжение кинематики:
            
    «She completes the smile, turns her gaze back to the camera, and holds a calm stillness. Camera remains stationary.»
          
    6. 
        

      


      
Метод 2: Ручной точный чейнинг (Frame-to-Video Precision)

      

        

          Используется в случаях, когда SceneBuilder дает слишком резкую смену освещения или если требуется гарантированный переход в конкретную позу.
        

        
    
          
  1. В плеере клипа 1 сделать экспорт последнего кадра: clip1_last_frame.png.
    2. 
          
  2. Открыть вкладку Video, режим Frames to Video.
    3. 
          
  3. Поместить clip1_last_frame.png в слот First Frame.
    4. 
          
  4. Если есть целевая поза финала, поместить ее в Last Frame (модель плавно интерполирует движение между ними).
    5. 
          
  5. Сгенерировать сегмент 2 на 8 секунд.
    6. 
          
  6. Соединить сегменты на таймлайне с жесткой склейкой (0-frame jump cut).
    7.
