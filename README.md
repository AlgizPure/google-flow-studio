# Google Flow Studio & Video Lab (PWA)

Профессиональное мобильное веб-приложение и инженерная база знаний для работы в **Google Flow**, генерации видео через **Veo 3.1** и **Gemini Omni Flash 1.1**, тонкой настройки кастомных инструментов во вкладке Tools и сохранения идентичности персонажей и голоса бренда.

## Модули системы
1. **Обзор & Архитектура:** Полная карта компонентов Google Flow (Veo, Omni, Nano Banana Pro, SceneBuilder).
2. **Аудит меню & Вкладок:** Детальный разбор каждого переключателя и параметра в Images, Video, Characters, Scenes, Uploads, Tools.
3. **Вкладка Tools & Тонкий кодинг:** Декларативная JSON/React схема инструмента `Skinerica Living Skin Video Engine` для создания кастомного микроприложения в Google Flow.
4. **Промпты & Разбор ошибок:** Пост-мортем сбоев в `flow-prompts-v1.html`, интерактивный генератор промптов с копированием в 1 клик для рекламных носителей (m1–m6) и Эрики.
5. **Голос & Клонирование:** Акустический паспорт голоса Эрики (ТоВ v3.1), инструкция создания 30-секундного аудио-якоря и привязки к модели.
6. **Склейка >8s & Сцены:** Инструкции по созданию непрерывных длинных видеороликов через SceneBuilder Extend (+7s) и точный Frame-to-Video чейнинг.
7. **Лимиты Ultra & Экономика:** Тарифная сетка, скидка 50% («Half-Price») на видео для подписки Ultra, лимиты параллельности и суточный троттлинг (Velocity Governor).

## Стек
- Zero-build vanilla web architecture (HTML5, CSS3, ES6 JavaScript)
- Service Worker для оффлайн-работы и установки PWA
- Адаптивный мобильный UI с поддержкой темной и светлой темы
